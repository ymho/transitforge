# ADR 0004: 国土数値情報から駅・路線カタログをローカル生成する

- ステータス: Accepted
- 日付: 2026-07-28
- 決定者: TransitForge開発者

## コンテキスト

列車の車体色を行き先駅の所属路線に合わせるには、駅と路線の所属関係が必要である。
`train_index.json` は駅名を持つが、路線名や事業者名を持たない。国土数値情報の駅GeoJSONは
必要な事業者、路線、駅名、座標を持つ一方、全量をそのままビューワー入力やGit管理対象に
する必要はない。

## 決定

`tools/build_station_line_catalog.py` により、指定された駅GeoJSONから対象事業者だけを抽出し、
`viewer-input/station_line_catalog.json` をローカル生成する。元GeoJSONと生成物はGit管理せず、
生成手順、入力契約、判定ロジック、テストをバージョン管理する。

カタログは事業者、正式路線名、所属駅、駅代表座標を保持する。表記揺れは生成時に正規化する。
ラインカラーは別のドメイン表で管理し、添付路線図から色を確定できない路線はグレーとする。

## 影響

- 駅ごとの手書きカラー表を持たず、元データから所属関係を再生成できる。
- 複数路線駅は列車の停車駅列を使って到着路線を選べる。
- 山陽線など地域で色が変わる正式路線は、駅代表座標を使った区間判定が必要になる。
- 開発開始前に派生カタログの生成が必要になる。

## 検証

- 対象事業者以外が生成物に含まれないこと。
- 既知の事業者名表記が正規化されること。
- 京都、岡山などの複数路線駅で停車駅列に応じた色になること。
- 色を定義していない路線がグレーになること。
