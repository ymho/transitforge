# ADR 0051: コンシェルジュのキャラクター機能を廃止する

- ステータス: Accepted
- 日付: 2026-09-12
- 関連: Issue #374、ADR 0035、0038、0044

## 背景

旅行相談を個別化するため、プロフィールから8人のキャラクターを選定し、画像・固有名・
役割・語尾のPromptを使っていた。利用者の方針変更により、この人格表現を廃止する。
旅行相談やプロフィール利用そのものの廃止ではない。

## 決定

- 表示名は「コンシェルジュ」とし、画像・キャラクターの紹介・固有の役割表示を削除する。
- 選定・採点・キャラクター定義・専用Prompt・画像8枚とその専用asset検査を削除する。
- 配布する静的資産がなくなるため`frontend/public`の存在を必須にしない。空のディレクトリや
  成功だけを返すasset検査は残さず、workspaceの他の境界検査は維持する。
- プロフィール保存後の選定待機と紹介画面を削除する。旅のスタイル確認と、会話を開く
  「旅をはじめる」操作は維持する。
- `conciergeInstruction` / `personaInstruction`の生成・伝達・Context fieldを廃止する。
  共通System Prompt、Tool、モデル設定、安全制約には変更を加えない。
- ADR 0035のプロフィール保存・allowlist投影、ADR 0038の単一Runtime、ADR 0044の
  Bedrockによる判断を維持する。代わりの人格やフロント専用の会話フローを追加しない。
- 保存キー・プロフィールversion・会話UUID・履歴・旅程・Feedbackは移行も削除もしない。
  過去の会話本文に含まれるキャラクター名を書き換えない。ゲストユーザのアイコンは対象外。

## 検証

- 新規登録、登録済みでの起動、プロフィール再編集、会話開始をDOMテストで確認する。
- 旧人格フィールドはモデル向けContextへ含めず、出発地・嗜好・日程・関連会話は保持する。
- 既存の会話Session・履歴・旅程復元テストを維持する。
- test / build / architecture / workspace / Smoke Evalを実行し、固定Evalと実モデルによる
  品質評価を区別する。Promptの人格除去による実応答品質は別途Live Evalで比較する。
