# ADR 0014: 最新運行スナップショットを現在表示の正本にする

- ステータス: Accepted
- 日付: 2026-08-14

## 背景

時刻表だけでは遅延 行き先変更 運転取りやめを表現できない
正規化済み遅延スナップショットには列車番号 遅延分 行き先が含まれる

## 決定

- 現在時刻付近のリアルタイム表示では遅延スナップショットを正本にする
- スナップショットに存在しない時刻表列車は表示しない
- 遅延分だけ時刻表上の位置を後ろへ移す
- 行き先はスナップショットの値を優先する
- 行き先変更列車は遅延ハローの赤色版で表示する
- 利用者は時刻表どおりの表示へ切り替えられる
- 現在時刻付近以外は時刻表表示だけを使う
- 取得元の一部に失敗したスナップショットは適用しない

リアルタイム適用範囲は収集時刻と実時刻 表示時刻の差がそれぞれ5分以内とする

## 影響

- 運転取りやめと行き先変更を地図へ反映できる
- 遅延列車の表示位置が計画位置より実態へ近づく
- 時刻表表示に戻して運行整理前のダイヤと比較できる
- 変更後の行き先が時刻表経路上にない場合は行き先表示だけを更新し 経路自体は補正しない
- 過去の運行再現には履歴スナップショットの読込が別途必要になる
