# ADR 0014: 最新運行スナップショットを現在表示の正本にする

- ステータス: Accepted
- 日付: 2026-08-14

## 背景

時刻表だけでは遅延 行き先変更 運転取りやめを表現できない
正規化済み遅延スナップショットには列車番号 遅延分 行き先が含まれる

## 決定

- 現在時刻付近のリアルタイム表示では遅延スナップショットを正本にする
- スナップショットに存在しない時刻表列車は表示しない
- 遅延分だけ時刻表上の位置を後ろへ移す
- 行き先はスナップショットの値を優先する
- 行き先変更時は元の行き先を二重線で消し 変更後の行き先と併記する
- 行き先変更後の終着駅へ到着した列車は遅延を加味した到着時刻から表示しない
- 収集時点で同じ位置へ30分を超えて在線する列車は停車中として表示する
- 区間内の途中駅へ行き先が短縮された列車は遅延ハローの赤色版で表示する
- 最新運行スナップショットを使う表示をデジタルツインモードと呼ぶ
- 利用者はデジタルツインモードとシミュレーションモードを切り替えられる
- デジタルツインモードは実時間で常時再生し 再生停止と速度変更を無効にする
- 混雑操作はデジタルツインモードだけ 行先アーチは両モードで有効にする
- 現在時刻付近以外はシミュレーションモードだけを使う
- 取得元の一部に失敗したスナップショットは適用しない

リアルタイム適用範囲は収集時刻と実時刻 表示時刻の差がそれぞれ5分以内とする

## 影響

- 運転取りやめと行き先変更を地図へ反映できる
- 遅延列車の表示位置が計画位置より実態へ近づく
- シミュレーションモードに切り替えて運行整理前のダイヤと比較できる
- 変更後の行き先が時刻表経路上にない場合は行き先表示だけを更新し 経路自体は補正しない
- 同じ列車番号の区間分割と環状線の方向表示は行き先変更として扱わない
- 過去の運行再現には履歴スナップショットの読込が別途必要になる
