# ADR 0020: 旅行プロフィールを端末内へ保存する

- ステータス: Accepted
- 日付: 2026-08-16

## 背景

曖昧な旅行相談に答えるには 普段の出発地や同行者 好みを参照できる必要がある。一方で
今回だけの目的地や日程は 普段の嗜好とは分離しなければならない。

## 決定

- 普段の情報を`UserProfile`として`localStorage`の`transitforge.travel-profile.v2`へ保存する
- 今回の目的地 日程や条件は保存プロフィールへ混ぜず`TripContext`として扱う
- 初回は7ステップの旅行オンボーディングを表示し コンシェルジュから確認 編集 削除できるようにする
- サーバーや外部提供者へプロフィールを送らない
- 興味や旅行ペース 許容度は将来の順位付けに使える0から1の値として保存する

## 影響

- アカウントなしで利用者ごとの初期条件を持てる
- 将来は`UserProfile`と会話から得た`TripContext`を候補生成へ渡せる
- 端末データを消去するとプロフィールも消える
