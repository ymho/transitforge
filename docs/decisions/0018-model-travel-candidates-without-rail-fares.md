# ADR 0018: 鉄道経路を正本にし 鉄道運賃を除外した旅行候補を組み立てる

- ステータス: Accepted
- 日付: 2026-08-16

## 背景

TransitForgeは自前の時刻表と運行情報で鉄道経路を確定できる。一方で鉄道運賃と料金は
正確な算出に必要な情報を保持していない。宿泊と体験は外部提供者から価格を取得できるため
移動を中心にした旅行候補へ追加できる。

## 決定

- `TravelCandidate`は確定済みの`JourneyRouteResult`を必ず1件持つ
- 宿泊と体験は提供者非依存の`TravelOffering`として保持する
- 旅行費用は宿泊と体験の既知の円価格だけを合計する
- 鉄道運賃と料金は取得 推定 表示 合計のいずれにも含めない
- 価格不明の候補は除外せず `hasUnpricedItems`で明示する
- 提供者ごとのAPI実装は後続のアダプター層へ置く

## 影響

- 経路の正確性を外部の宿泊や体験APIへ委ねない
- 料金が不明な項目を推定額として誤表示しない
- 新しい提供者を追加しても画面と経路検索の契約を変えずに済む
