# ADR 0100: 利用者の予約マークをTripの予定に保存する

- ステータス: Accepted
- 日付: 2026-10-11

## 判断

利用者が付ける「予約済 / 予約不要」はTrip.itemsのoptional bookingStatusへ保存し、既存CASと共有権限で更新する。予約番号・Providerの確認事実・独立revisionを持つReservationはADR 0055のまま別resourceにする。

ADR 0055の「Trip.itemsへ予約状態を埋め込まない」は実予約記録に適用し続けるが、利用者の単純な自己申告マークに限って本判断で拡張する。マークをReservationFactや成立性の証拠へ変換しない。

## 理由と影響

簡単な印のために公開Reservation CRUDと独立更新競合を増やす必要がなく、共同編集者とAIが旅程から同じ自己申告を参照できる。未確認のホテル・移動は旅程確定のダイアログで注意を出すが、確定は妨げない。予約不要を明示できるため自由席や予約のない移動も扱える。

予定対象・日時変更では印を解除し、公式しおりと旅程の分岐へ持ち越さない。詳細は[予約マーク](../architecture/trip-booking-marks.md)を参照する。
