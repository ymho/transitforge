# Place写真メタデータの小標本監査

2026-09-18、公式ページの公開alt/URLと画像3枚を目視比較した。画像本体は保存・配布せず、隣接テストにメタデータと観測結果だけを固定する。

| 公開ページ / 画像 | 目視分類 | selector |
| --- | --- | --- |
| [空中庭園展望台](https://www.skybldg.co.jp/observatory/) / `i_observatory_slide01.jpg` | 通常の風景写真 | 採用 |
| [梅田スカイビル](https://www.skybldg.co.jp/) / `event_seika_0918.webp` | 文字を合成したイベント告知 | 残留 |
| [Recruit Webサービス](https://webservice.recruit.co.jp/) / `banner/hotpepper-s.gif` | 文字入りバナー（対照標本） | 除外 |

この意図的な小標本では加工画像2枚中1枚が残留、通常写真1枚の過剰除外は0。検索母集団の精度を示す数値ではない。ファイル名・path・altに手掛かりがない文字入り画像は検出できない。イベントという語を一律除外すると通常のイベント写真も失うため、今回追加しない。

観光写真selectorの検査であり、クレジットバナー表示や宿泊Providerの画像在庫を除去する変更ではない。

後続課題候補: メタデータを通過した画像に限る任意のpixel検査について、費用・遅延・誤検出・権利条件を別途評価する。全画像へのOCR/visionは今回導入しない。
