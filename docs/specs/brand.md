# KAIHO ブランド表示

サービス表示名はKAIHO（懐宝）。内部識別子、パッケージ名、リポジトリ名、AWSリソース名、ストレージキーは互換性のため変更しない。

## ロゴ

共通の`brandLogoMarkup`から文字のみのKAIHOを表示し、シンボルやサブタイトルは付けない。Zen Kaku Gothic Newの500を使用する。KAIHOに必要な欧文字だけを同梱し、外部フォント通信を不要にする。SIL OFLライセンスも同梱する。

AIは文字色と背景色を反転した角丸の色面で示す。ヘッダーは柔らかいグレー、スマートフォンの写真上は白文字とAI部分の白背景・グレー文字。白い台座は設けない。AIの文字は周囲の86%とし、背景は大文字の実際の高さ（0.7em）より上下各0.03emだけ広くする。書体の行ボックスと実際の字面の差を補正し、背景と文字の中心位置を揃える。

参照画像のシンボルはベクターパスとして`frontend/public/favicon.svg`に置き、faviconに使用する。専用アプリアイコンは定義していない。

## トップ

入力欄のプレースホルダーは「週末にしたいことは？」「来週、出雲大社にいきたい」「リラックスできる旅を提案して」の順で4秒ごとに表示する。入力中・フォーカス中・画面非表示中は切り替えない。「例」は付けない。

紹介文は次の見出しと3段落を使用する。スマートフォンではロゴと紹介文を中央寄せにする。

### あなただけの旅を、一緒に形にします。

その昔、旅に役立つ情報をまとめ、懐に収めて持ち歩ける案内書や地図が「懐宝」と名付けられました。

旅に必要なものを、いつでも手元に。その思いを受け継ぎ、KAIHOは新しい旅のパートナーとして生まれました。

AIとともに、行きたい場所や体験したいことを一つの旅へ。旅先の発見から、移動や旅程づくりまで、あなたの旅づくりをサポートします。

由来の参考：https://rmda.kulib.kyoto-u.ac.jp/en/item/rb00011655

予約・決済など未実装機能を提供済みと説明しない。ブランドビジョンによって現行の地図・相談・旅程の構成や権限、状態管理を変更しない。

## 画面との統一

既存の赤系アクセントとライト背景を維持する。入力欄は36px、上下余白4pxに詰め、スマートフォンの16px入力と表示縮小を維持する。共有・公式しおりのカテゴリ、共有ダイアログ、公式しおりの取り込みも同じ色・余白・ボタン階層に揃える。

Desktopの上部メニューは各項目の囲い・塗り背景を外し、項目間の細い縦線と選択項目の下線で表示する。写真背景では白文字、通常画面では既存のアクセント色を使う。キーボードfocus表示と44pxの操作領域を保持する。
